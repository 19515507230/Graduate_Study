## 作业

1. 将ori文件夹中的pdf文件提取（复制）出来，在ori同级文件夹建立pdf文件夹，里面建立以pdf文件名字命名的文件夹， 里面放置相应的pdf文件（文件重命名为report.pdf），将 pdf文件夹压缩，最后将压缩后的文件删除。（本题目要求交互式的选择路径）。

```matlab
% 1. 获取ori路径
ori_path = uigetdir('请选择 "ori" 文件夹路径...');
pdf_path = fullfile(ori_path, '..\pdf');

% 2. 在ori同级文件夹建立pdf文件夹
if ~exist(pdf_path, 'dir')
    mkdir(pdf_path);
end

% 3. 获取ori文件夹中的所有pdf文件

fileList = dir(fullfile(ori_path, '*.pdf'));

for i = 1:length(fileList)
    % 获取当前处理的文件名 (例如 '010001.pdf')
    fileName = fileList(i).name;
    
    % 提取文件编号作为子文件夹名 (例如 '010001')
    [~, fileNum, ~] = fileparts(fileName);
    
    % 在pdf文件夹下建立以编号命名的子文件夹
    newSubDir = fullfile(pdf_path, fileNum);
    if ~exist(newSubDir, 'dir')
        mkdir(newSubDir);
    end
    
    % 构建源文件路径
    srcPath = fullfile(ori_path, fileName);
    
    % 构建目标文件路径 (将所有文件重命名为 report.pdf)
    destPath = fullfile(newSubDir, 'report.pdf');
    
    % 执行移动和重命名操作
    % movefile(srcPath, destPath);

    % 改为复制操作，以便多次运行
    copyfile(srcPath, destPath)
end

% 4. 压缩文件
zip('pdf_archive', pdf_path);
delete(fullfile(ori_path, '..\pdf_archive.zip'));
```

2. 随机生成一个正态矩阵，矩阵维数为3×5；将所有正数所在的行和列输出出来。用编程语言自动求出矩阵里面元素总数目。

```matlab
clear;clc;
% 1. 随机生成 3x5 的正态矩阵
M_normal = randn(3, 5);

% 2. 找出所有正数并输出其行和列
[row_idx, col_idx] = find(M_normal > 0);
disp('正数所在的行和列 (Row, Col)：');
disp([row_idx, col_idx]);

% 3. 自动求矩阵元素总数目
num_elements = numel(M_normal);
fprintf('矩阵元素总数目: %d\n', num_elements);
```

4. 随机生成两个10×1的向量，做两个向量之间的双样本t检 验，得到p值和t值。

```matlab
clear;clc;
% 1. 随机生成两个 10x1 的向量
vec1 = randn(10, 1);
vec2 = randn(10, 1);

% 2. 进行双样本 t 检验
[h, p, ci, stats] = ttest2(vec1, vec2);

% 3. 输出 p 值和 t 值
fprintf('t 检验结果：\nt值 (t-statistic): %.4f\np值 (p-value): %.4f\n', stats.tstat, p);
```

5. 小明同学出生日期是1990年1月20日，请问到2019年12月13日为止，小明多少岁（尽可能精确，岁数可以有小数点）？

```matlab
clear;clc;
% 1. 定义出生日期和截止日期
birth_date = datetime(1990, 1, 20);
end_date = datetime(2019, 12, 13);

% 2. 计算天数差并转换为岁（考虑闰年等精确天数）
% days() 计算总天数，使用 365.2422 作为平均年长度以获得高精度
total_days = days(end_date - birth_date);
age_precise = total_days / 365.2422;

fprintf('小明到 2019年12月13日的精确年龄为: %.4f 岁\n', age_precise);
```
