## 命名规则

### m文件命名规则

1. MATLAB 名称必须以字母开头；并且仅包含字母、数字或下划线；
2. 不能与内置函数名同名，会产生覆盖和冲突； 
3. 对大小写敏感；
4. 文件路径不能包含空格等特殊字符；

### 变量名命名规则

1. MATLAB 名称必须以字母开头；并且仅包含字母、数字或下划线；
2. 不能与内置函数名同名，会产生覆盖和冲突； 
3. 对大小写敏感；

>[!NOTE]
>变量名可以采用下划线命名方式或驼峰提命名方式。
>函数名最好使用驼峰提命名方式。

## MATLAB 语法小观

```MATLAB

% 创建多维数组：用','或' '区分同行不同列的元素，用';'或'\n'区分同列不同行的元素。
% 1. 创建一维行向量
array_1 = [1, 2, 3];
% 2. 创建一维列向量
array_2 = [1; 2; 3];
% 2. 创建多维数组列向量
matrix_3 = [1, 2; 3, 4];

% 创建特殊的多维数组
% 1. 元素为等差数列：array = start[:step]:stop step默认为1
array_4 = 1:5;  % [1, 2, 3, 4, 5]
% 2. 元素为[0,1]的随机数，均匀分布
matrix_5 = rand(3, 3);  % 3 x 3 矩阵

% 拼接多维数组
% 1. 按行拼接：使用','或' '
array_6 = [array_1, array_4];
% 2. 按列拼接：使用';'或'\n'
matrix_7 = [matrix_5; array_1];

% 访问多维数组中的元素：
matrix_8 = rand(4, 4, 4);
matrix_8([1,2], :, 2:3);  % 多维索引
% '()'中的','用于分割不同的维度，用一维数组指定在该维度所需访问的元素位置。该例子中，'[1, 2]'表示访问第一个维度的第一个和第二个元素；'2:3'相当于生成一个等差数列；':'表示该维度的所有元素；此处可以使用关键字'end'。
matrix_8(60);  % 线性索引

```

>[!NOTE] Tips
>1. MATLAB的程序文件是扩展名为.m的文件，数据文件是扩展名 为.mat的文件；
>2. 如果任何一个窗口找不到，都可以从MATLAB的layout选项中调出，最简单的方法是点default（恢复默认设置）；

## 作业

1. 在zuoye目录下建立sub文件夹， sub文件夹里面建立以ori文件夹里面的pdf编号命名的子文件夹， 接下来将ori文件夹里面的pdf放到对应编号的文件夹中并全部改名为report.pdf，最后删除掉sub 文件夹。作业提示：使用循环语句（自学）。

```matlab
% 1. 在zuoye目录下建立sub文件夹
if ~exist('sub', 'dir')
    mkdir('sub');
end

% 2. 获取ori文件夹中的所有pdf文件
% 使用 dir 函数列出所有 .pdf 文件
fileList = dir(fullfile('ori', '*.pdf'));

for i = 1:length(fileList)
    % 获取当前处理的文件名 (例如 '010001.pdf')
    fileName = fileList(i).name;
    
    % 提取文件编号作为子文件夹名 (例如 '010001')
    [~, fileNum, ~] = fileparts(fileName);
    
    % 在sub文件夹下建立以编号命名的子文件夹
    newSubDir = fullfile('sub', fileNum);
    if ~exist(newSubDir, 'dir')
        mkdir(newSubDir);
    end
    
    % 构建源文件路径
    srcPath = fullfile('ori', fileName);
    
    % 构建目标文件路径 (将所有文件重命名为 report.pdf)
    destPath = fullfile(newSubDir, 'report.pdf');
    
    % 执行移动和重命名操作
    % movefile(srcPath, destPath);

    % 改为复制操作，以便多次运行
    copyfile(srcPath, destPath)
end

% 4. 最后删除掉sub文件夹
if exist('sub', 'dir')
    rmdir('sub', 's'); 
end
```
